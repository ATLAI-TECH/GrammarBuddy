# Marta（西英双语记者兼译者，偶尔法语）— 设计评审 Round 1

评的是 `DESIGN.md` v1（2026-11-14，评审前）和 `INVESTIGATION.md`。
我的机器：MacBook Pro M2 16 GB，macOS 15。系统界面语言是英语（我这样的双语用户很多都这么设），键盘是西班牙语 ISO 布局。
说明：我不是程序员，这一轮没有查任何 SDK 或头文件，也没有运行任何东西。下面凡是涉及「某个 App 里技术上会怎样」的判断，都是**我没验证**的推测，已逐条标出。

## 结论（评分 4/10）

一句话：按这份设计做出来，我会留着它用来「读法语网页时选中看一眼译文」和「改一两句纯文本」，但我真正的工作（Pages / Google Docs / 邮件里上千词、带加粗斜体链接和引语的稿子）不会交给它，因为替换会丢格式、长稿只能整篇接受或整篇放弃、译文不能对照也不能在面板里改、西语和法语的质量和排版规则完全没有被测过，而且整份调查是在 macOS 26 上做的，我的 macOS 15 一次都没跑过。

## 我的任务和走查过程

### 任务 1：第一次安装，在 Safari 里读一段法语报道（macOS 15）

文字：Le Monde 一段约 120 词的正文，含 `« … »` 引号和 `:`、`?` 前的窄空格。

1. 下载 DMG、拖进应用程序、打开。§3.1 说有签名公证，§2.6 说启动时不弹权限窗口。清楚。
2. 引导第 1 步「试一下」：示例文字带错误，让我按 ⌃⌥G。这时我还没装 LM Studio（第 3 步才选后端），改错默认用本地模型（§5.1）。**设计稿没说这一步在没有后端时显示什么。** 我会看到一个报错，第一印象就是「坏的」。（M1-17）
3. 第 2 步辅助功能权限：说明清楚，可以跳过。好。
4. 第 3 步后端：没找到 LM Studio，给链接，并说「翻译不需要这一步」。这句话对我很重要，好。但没告诉我该下哪个模型才能改**西班牙语和法语**（调查只测了英文学术文和英译中）。（M1-11）
5. 回到 Safari，选中法语段落，按 ⌃⌥T。面板出现。§2.3：检测到法语，不是母语 → 译成母语。**我的系统语言是英语，所以「母语」默认是英语，「常用外语」默认也是英语。** 两个一样时怎么办，设计稿没写。我实际想要的是译成西班牙语。引导三步里也没有一步让我确认这两个语言。（M1-04）
6. 第一次用法→英（或法→西）语言对，系统弹下载语言包窗口，面板提前说一句（§2.3）。可以。但 §6.5 说 macOS 15 只能靠面板里常驻的 `.translationTask`，而调查机器是 macOS 26.6.1，§10 的未验证清单里没有「macOS 15 上的系统翻译」这一行。我的整条翻译路径没人跑过。（M1-08）
7. 网页正文不可编辑，默认按钮是「复制」（§2.3）。清楚，合理。
8. 面板里「翻译只显示译文」（§2.2）。读新闻够用；但我想核对某一句时，原文被面板盖在下面（面板贴着选区下方，420 pt 高）。能凑合。

第一次成功用上：下载 → 打开 → 引导 3 步 → 授权辅助功能 → 选中按键 → 下语言包，大约 6 步，翻译这条线可以接受。前提是第 5、6 步真的走得通。

### 任务 2：把 Pages 里一篇 1,400 词的西语特稿译成英语

文字：约 8,800 字符，14 段，有 2 个加粗小标题、若干斜体书名、6 个链接、5 处直接引语（`«…»` 和 `—` 对话破折号）。

1. ⌘A 选全文，按 ⌃⌥T。读：辅助功能接口读 `kAXSelectedTextAttribute`（§4.1），读到的是纯文本（§4.2 已承认）。
2. 8,800 字符落在 3000–20000 档：按段落拆开，逐段处理、逐段显示（§5.3）。**这一条对系统翻译是否同样适用，设计稿没说**；§5.4 的「系统翻译 1 秒内」也没说是多长的文字。（M1-07）
3. 语言检测：是对整个选区测一次，还是每段测一次？没写。我的稿子里有一整段是英语引语，如果逐段检测，这一段会被判成「非母语」而往反方向翻，或者原样留下。面板里只能改**目标**语言，看不到也改不了它检测出的**源**语言。（M1-05）
4. 结果出现在 480×420 pt 的面板里，只有译文。1,400 词的译文要滚十几屏，原文在面板后面的 Pages 里。**我没法对照**。这是译者最基本的动作。（M1-03）
5. 我发现第 3 段有个机构名译错了，想在面板里改掉再替换。设计稿没有任何一处说结果可以编辑；「逐条接受改动」在里程碑的「之后」。我只能整篇替换后回 Pages 里找到那一处再改。（M1-03）
6. 同一个术语（比如 *Fiscalía*）在第 2 段和第 9 段被译成了两个不同的词，因为各段独立处理。没有术语表，也没有「不要翻译」的词表。（M1-06）
7. 按 ⏎ 替换。§4.2 的已知限制：Pages 里选区内的加粗、斜体、链接**全丢**，v1「只在面板里提示」。6 个链接没了，小标题不再是粗体。提示在什么时候出现（按 ⏎ 之前还是之后）没写。整篇被替换成什么段落样式也没写。（M1-01）
8. 于是我改用「插入到原文下方」（§2.3），想保留带格式的原文、把译文放下面做对照稿。这个按钮只在这里出现了一句：插在选区末尾之后还是每段之后？带不带分隔？用什么样式？没写。（M1-14）
9. 我想撤销。**整份设计稿没有出现「撤销」两个字。** 在 Pages 里按一次 ⌘Z 能不能回到替换前、格式回不回得来，没有说明也没有列入测试。（M1-09）

结论：这个任务最后只能「复制译文，粘到另一个文档里，自己把格式重做一遍」。那和我现在把文字贴进 DeepL 没区别，还少了对照视图和术语表。

### 任务 3：在 Safari 的 Google Docs 里给一篇 1,800 词的英语稿改错

文字：约 11,000 字符，20 段，有链接和斜体。

1. ⌘A，⌃⌥G。Google Docs 的正文是网页自己画的，辅助功能接口大概率读不到选区（**我没验证**），于是走剪贴板兜底：模拟 ⌘C，最多等 300 ms（§4.1）。11,000 字符在 Google Docs 里 300 ms 够不够，**我没验证**，设计稿也没测；不够的话我会掉进「输入模式」，莫名其妙。（M1-02）
2. 走兜底时拿不到选区坐标，面板出现在鼠标旁（§2.2）。可以。但「是否可编辑」是靠 `AXUIElementIsAttributeSettable` 判断的（§4.1），兜底路径下这个判断从哪来？默认按钮是「替换」还是「复制」？没写。（M1-02）
3. 改错：20 段逐段跑。按 §5.4 的数字（100 词 2 秒）估算，1,800 词大约 40 秒以上。这期间有没有进度（第几段 / 共几段）、能不能取消、我点回文档继续写会不会把面板关掉、第 12 段模型出错时前 11 段的结果还在不在，都没写。（M1-07）
4. §5.2 的「长度相差超过 30% 判为跑偏、不提供替换」是按整篇算还是按段算？如果是按段，一段出问题是整篇不能替换，还是只跳过那一段？没写。（M1-07）
5. 结果：差异视图里比如 40 处修改。其中 3 处我不同意（它把英式拼写改成了美式）。我只能全部接受或全部不要。（M1-03、M1-10）
6. 我按 ⏎。**这里我真的担心**：§2.2 说面板不抢焦点、原 App 保持前台，那 ⏎ 这个键是谁收到的？如果是 Google Docs 收到，我选中的 1,800 词会被一个换行符替换掉。Tab、数字键 1–4、⌘C、Esc 同理。设计稿两处说法对不上，没解释键是怎么被面板拿到的，也没说面板开着的这 40 秒里我在别处还能不能正常用 ⌘C。（M1-15）
7. 假设键没问题。写回前「重新读一次选区」确认没变（§4.2）——兜底路径下这意味着再模拟一次 ⌘C？然后粘贴兜底：放进剪贴板 → ⌘V → 500 ms 后恢复原剪贴板。Google Docs 处理大段粘贴比较慢，500 ms 后剪贴板已经被换回去，贴进去的可能是旧内容（**我没验证**）。贴进去的是纯文本，链接和斜体丢。（M1-01、M1-02）
8. §8 的手工兼容性表列了 Safari 和 Chrome，但没单列 Google Docs。它和普通网页输入框是两回事。（M1-02）

### 任务 4：在 Apple Mail 里用法语回一封信

做法：先用西语写 80 词，选中，⌃⌥T，目标语言临时改成法语，替换；再对法语结果按 ⌃⌥G 改错。

1. 西语是我的母语 → 默认译成「常用外语」英语（§2.3）。我在面板里临时改成法语。可以。但下次再回这位法国联系人，又要改一次；面板改过的目标语言记不记得住、按什么记（按 App？按语言对？）没写。（M1-04）
2. 西语里的 tú / usted 要对应法语的 tu / vous。翻译没有任何「正式 / 非正式」选项；「语气」是另一个操作，而且只对同语言改写。系统翻译会替我选一个，我无法控制。（M1-12）
3. 替换。Mail 的写信窗口，辅助功能接口写不写得进去属于 §10 第一行的未验证事项，接受。回信里引用的原邮件我没选中，不受影响。
4. 对法语结果按 ⌃⌥G 改错。法语在 `; : ! ?` 前和 `« »` 内侧要用不换行空格（U+00A0 / U+202F）。小模型很可能把它们「规范化」成普通空格或直接删掉，或者把 `« »` 换成 `" "`。差异是「词级」的（§3.2），只有空格种类变了的改动在差异视图里显示不显示？设计稿没提。看不见的改动我就会不知情地接受。（M1-10）
5. 改错的提示词要求「输出语言和输入相同」，好。但改错模型处理法语、西语的质量，调查里一个字都没有，§10 也没列。（M1-11）

### 任务 5：在 Pages 里润色一段带直接引语的西语

文字：`—¿Y quién va a pagar esto? —preguntó la alcaldesa—. «No hay presupuesto», insistió.` 加上前后各两句叙述。

1. 我选中的恰好是一句完整引语：`«No hay presupuesto para esto, y lo saben.»`，按 ⌃⌥G 再按 2 切到润色。
2. §5.2 输出清洗会去掉「首尾多余的引号」。我的原文首尾本来就是引号。清洗怎么区分「模型多加的」和「原文就有的」？没写。按字面做，我的引号会被吃掉。（M1-13）
3. 更要紧的：润色「可以换词、调语序」，保留项是「原意、专有名词、数字、引用标记」（§5.1）。「引用标记」看上去指论文里的 [1] 这类，不是引号里别人说的原话。对记者来说，**直接引语里的字一个都不能动**；模型把被访者的话润色了而我没逐字看出来，是职业事故。（M1-13）
4. 开头的 `¿` `¡` 和对话破折号 `—`（raya）是西语排版的一部分。小模型输出时掉 `¿`、把 raya 换成英式引号都是常见毛病（**我没在这个模型上验证**）。设计稿没有任何一条针对非英语标点的规则或测试。（M1-10）
5. 我选一整段时通常带着末尾的换行。模型返回的文字多半不带。替换后这一段会和下一段粘在一起。设计稿没说首尾空白和换行要原样保留。（M1-16）

### 任务 6：把一段法语通稿译成英语（给英语媒体供稿）

1. 选中法语，⌃⌥T。规则：非母语 → 译成母语（西语）。我要的是英语。每次都要手动改。
2. 「母语 / 常用外语」只有两个槽位。我的实际情况是：西语和英语都是工作语言，法语只读不写。我需要的是「西↔英互译；法语→看我上次选了什么」。两个槽位表达不了。（M1-04）
3. 法→英、法→西如果系统翻译在内部要经过英语中转，法→西的质量会打折（**我没验证**系统翻译是否这样做）。设置里可以整体换成「用 AI 模型翻译」，但那是设置页里的全局开关，面板里不能就这一次换引擎对比一下；⌘R 重试对系统翻译大概只会得到同一个结果。（M1-18）
4. 我给拉美媒体供稿时要拉美西语，给伦敦的编辑要英式英语。设置里只有「语言」，没有地区变体。（M1-10）

## 优点

1. **§2.3「翻译不需要 AI 后端」+ §2.6 第 3 步明说这一点**：我不装 LM Studio 也能马上得到一个有用的功能，这是我愿意先装上试试的唯一理由。
2. **§2.3 不可编辑时默认「复制」、可编辑时多一个「插入到原文下方」**：后者正是译者做对照稿的习惯动作，方向对（细节见 M1-14）。
3. **§4.2 写回前重新读选区、不一致就不替换并说明原因；写完再读一次确认**：我在等长稿结果时确实会手痒去点别处，这条能防止它把文字贴到错误的位置。
4. **§7 隐私**：未发表的稿子和线人相关的文字不出本机，历史只在内存、退出清空，剪贴板带不记录标记，远程接口有橙色「云端」标记。对记者这是实打实的卖点，也是它相对 DeepL / Grammarly 我唯一会考虑换的原因。
5. **§5.3 长文本按段落处理、保持段落结构、逐段显示**：比「超过多少字就拒绝」好，20,000 字符的上限也覆盖了我大部分稿子（约 3,000 词）。
6. **§4.2 和 §10 把富文本会丢格式、哪些没验证老实写出来了**：我不同意 v1 的处理方式，但至少没有瞒我。
