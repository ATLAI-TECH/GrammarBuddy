### 关于「默认动作的规则我记不记得住」

我把自己一天里会遇到的情况按 §2.4 列了一下：

| 我在哪里做什么 | ⏎ 做的事 | ⌘⏎ 做的事 |
|---|---|---|
| Safari 读法语网页 | 复制 | 无 |
| Pages 改错（分片可行） | 替换 | 无 |
| Pages 改错（分片不可行，事先不知道） | 复制 | 替换并丢格式 |
| Pages / Mail 翻译 | 插入到原文下方 | 替换并丢格式 |
| Google Docs 改错 | 复制 | 粘贴到光标处 |
| Google Docs 翻译 | 说法不一 | 说法不一 |
| 任何地方触发了检查 | 复制 | 仍要替换 |
| 点过面板外面之后 | 复制 | 没写 |

⏎ 有三种意思，⌘⏎ 有三种意思（加上输入模式里的「提交」是四种）。我记不住，只能每次读底栏。读底栏本身没问题，问题是：我按 ⏎ 以为替换了，其实是复制，面板一关我就回去接着写，过后才发现稿子没改。设计稿没写执行动作之后给我什么反馈（M2-09）。

## 优点

1. **§2.4「拿不准就复制」+ 翻译在富文本里默认「插入到原文下方」**：上一轮我的 P0 就是替换毁格式。现在默认动作不动原文，丢格式的动作要 ⌘⏎ 并且事先数给我看会丢什么（§5.4）。方向完全对。
2. **§2.5 对照视图 + §2.7 长文本的面板状态**：按段上下对照、面板自动放大并记住尺寸、进度、分两次的 Esc、失败的段单独重试、同时显示词数。译者需要的基本动作这回都有了。
3. **§2.5 方向显示「法语 → 西班牙语」两边可点，整个选区判一次，把握不大先问，夹杂的外语段标出来让我选**：比上一轮只有两个槽位、看不到源语言强很多。
4. **§6.1、§6.3、§6.4 对引语和非英语标点的处理**：只去掉输出里多出来的引号；润色默认不动引语；`¿ ¡ « »` 和不换行空格有不靠模型的机械检查；引语内的改动另色并计数。这是我见过的同类工具里唯一把「被访者原话不能动」当回事的。
5. **§2.2 逐处取舍和「编辑」视图**：40 处修改不再是全收或全弃。
6. **§12 把 macOS 15 的翻译全流程、非英语语言对、非英语的改错质量都列进未验证，并写了在哪个里程碑验证、不行怎么退**：我的系统版本和我的语言不再是没人管的角落。
7. **§2.11 历史里保留原文、可「复制原文」**：撤销靠不住时的最后一道保险。
