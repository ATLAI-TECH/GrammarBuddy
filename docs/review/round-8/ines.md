## ⏎ 还是 ⇥：读完新的 handleKey 之后

**我改变了一半看法。**

上一轮我反对 ⏎ 的两个依据是具体的缺陷：第二下 ⏎ 会漏进 App、带修饰键的 ⏎ 被吃掉。这两个现在都没有了：

- `reviewing` 覆盖了写回的那段时间，`writing` 期间的采用键 / 跳过键 / Esc 直接吃掉；
- 长按不连续采用（`isRepeat`）；
- 最后一条之后 0.8 秒内的采用键吃掉；
- 只差大小写、带数字的记号要用鼠标确认；
- 任何带修饰键的键关卡片并放行；别的 App 到前台立刻结束。

在「我按了 ⌃⌘J，进入逐条过」这个场景里，这是一个我明确要求进入的模式，卡片在屏幕上，⏎ 表示「是」和所有对话框一致，对不写代码的人比 ⇥ 更好猜。四位有宿主的评审也是这么说的。**这个场景下我同意 ⏎ 做默认**，不再坚持默认 ⇥。设置里那一项的写法（`⇥ Tab (→ skips, ⏎ stays with the app)`）也清楚。

我没有改变的另一半：上一轮我写的第 3 个条件（「只有 ⌃⌘J 进入的复查模式里 ⏎ 才采用，鼠标点开的卡片只认鼠标」）没有做，而这才是剩下的风险所在。`clicked()` 对下划线词上的任何一次单击都调 `open()`，`open()` 无条件 `reviewing = true` 并启用按键拦截。于是：

- 我点进 `recieve` 想自己改，按 ⌫：这个键被吃掉，这条建议被「忽略」，下划线消失，词还是错的，卡片跳到下一条。我丢了一个键，还丢了一条对的建议。
- 我点到行尾一个有下划线的词上放光标，按 ⏎ 想换行：采用了一条我没看的建议，没有换行。
- 换成 ⇥ 模式也一样：点完之后按 → 想挪一格光标，被当成跳过吃掉。

所以问题不在「⏎ 还是 ⇥」，在「没有请求键盘模式的时候，不要接管打字用的键」。状态机把「漏键」修好了，但把「抢键」的范围从一个键扩大到了三个（⏎、⇥、⌫）。

**如果有人仍然要为默认 ⇥ 辩护，最有力的理由**是代价不对称：⏎ 出一次错，在聊天框里是一条已经发出去的消息，或者一处没看就被改掉的文字；⇥ 出一次错是焦点挪了一下或多了一个缩进，都能撤回。加上 ⇥ 接受建议已经被编辑器的内联补全教给了很多人。这个理由成立的前提是「⏎ 仍然会出错」，这一点现在只能靠测试判断。

**可以验证的判断标准**（5–8 个不写代码的写作者，每人 30 分钟，一半时间在 ⏎ 即发送的聊天框里，一半在文档里；不告诉他们按键，只给卡片上的提示；按键拦截处记日志）：

| 指标 | 怎么量 | ⏎ 默认是对的 | 我是对的（应改 ⇥，或至少拆开点击和 ⌃⌘J） |
|---|---|---|---|
| 误采用 | 采用后 5 秒内 ⌘Z，或同一个词又被手动改回 | ≤ 1 次 / 200 次采用 | > 1 次 / 50 次 |
| 被吃掉的键 | 评审中被拦下的 ⏎ / ⇥ / ⌫，之后 1.5 秒内同一个键又按了一次（用户本来是要打这个键） | 点击打开的卡片里 < 2% | 点击打开的卡片里 > 10%（我预计 ⌫ 最高） |
| 漏出去的键 | 评审结束后 2 秒内 ⏎ 进了宿主，且用户随后撤回或补发更正 | 0 次 | 任何一次「没改完的消息发出去了」 |
| 第一次就会 | 第一次看到卡片，不看提示行，10 秒内按对采用键的人数 | ⏎ 明显多于 ⇥ | 两者接近，或 ⇥ 更多 |

如果前三项里 ⌃⌘J 打开的卡片都达标、只有点击打开的不达标，那就证明应该拆，而不是换键。这是我预计的结果。

## 卡片的样子（wang 的截图 + 代码）

`w8-card1-1.png`：`was → were`，右上 `1/11`，一行 Accept / Ignore / Ignore sentence，一行 `⏎ accept, next · ⇥ skip · ⌫ ignore · Esc close`。

- **Accept 不像主按钮。** 代码里它是 `.borderedProminent`，但卡片是不激活的面板，系统把它画成和 Ignore 一样的灰色。两个一样的灰按钮并排，眼睛找不到「是」。用自己的填充色画（I8-05）。
- **计数是 `1/11`，采用几条之后是 `1/5`**（同一位评审的两张截图）。`open()` 用的是「这条在剩余标记里的序号 / 剩余总数」，从头按 ⏎ 过的时候分子一直是 1，分母往下掉。它想说的是「还剩 5 条」，那就写「还剩 5 条」（I8-06）。
- **提示行有四个动作，按钮有三个，对不上**：按钮是 采用 / 忽略 / 这句都忽略；键是 采用 / 跳过 / 忽略 / 关闭。「跳过」没有按钮，「这句都忽略」没有键，「忽略」和「跳过」的区别（下划线留不留）要按过才知道。
- 只差大小写的卡片（wang 的 `w8-pcr-1.png`：`Pcr → PCR`，橙色一行「Case or identifier change: click Accept to confirm · ⇥ skip · Esc close」）：意思清楚，橙色也对。但它叫我去点的那个 Accept 恰好是灰的（见第一条），而且这行字把卡片撑宽了一半，从 `was → were` 跳到这一张时卡片会变形。提示行硬写了 `⇥ skip`：换成 ⇥ 采用之后，这张卡片上按 ⇥ 是「拒绝并晃一下」，提示却说 ⇥ 是跳过（那时跳过是 →）。这一行也没提 ⌫（I8-08）。
- ⇥ 模式的卡片（priya 的 `c1-tabkey-1.png`）：第一行是 `question → questions`，提示行是 `⇥ accept, next · → skip`。**同一张卡片上「→」有两个意思**：上面是「改成」，下面是「右方向键」。这是我建议 ⇥ 模式下不要用 → 做跳过的第二个理由。
- 结束时一律提示「All suggestions here are done」。`finishReview` 在走到末尾时调用，不管我跳过了几条、也不管我是从文档中间开始的（前面的没看过）。这句话有时是假的（I8-07）。
- ⌃⌘J 这个键只在设置里出现过一次。卡片、选中按钮、菜单里都没有。用鼠标点开第一张卡片的人不会知道可以用键盘从头过一遍（I8-11）。
- 下划线（marta 的 `es-card-0.png`）：2 pt 紫色实线，贴着词，宽度跟词走，看着干净。合并后的两个词是一条连续的线，对的。

- 点一下可以单独采用（步骤 9），写回的结果和我点的一致。英文直引号和法文 `« »` 都认。

打磨：

- 没采用的那几处**只显示原词，不显示它想改成什么**。说明让我「点一下采用」，但我得先点了才知道采用的是什么。应该把建议用灰色、虚线放在旁边，或悬停时显示（I8-09）。
- 橙色小引号紧贴在引语里的词后面（`where is❝ the button`），在一句本来就带引号的话里，第一眼像一个多出来的标点。换成词下面的橙色虚线，或者把角标放到词的上方。
- 「change(s)」：按数量写单复数。
- 一处修改被拆成两条时（`where is the button → where the button is` 变成「删 is」和「改后半句」），只点其中一条会改坏。上一轮的合并只管相邻的；引语里默认不采用，所以这里风险小，记一笔。
- **对我的职业，这个默认值有一半时候是反的**（I8-10）。我每天写的是带引号的界面文案：`The button says "Try it free during 14 days"`。引号里的正是我要它查的。面板里还好，有说明，点一下就行（步骤 10）；但实时标记里引语是**直接不标**的，没有任何痕迹，我会以为它查过了、没问题。建议：实时标记里引语内的问题用灰色虚线标出来（表示「有，但我没碰」），或者在设置里给一个「引号里的也检查」。
- 读代码：直双引号是按出现顺序两两配对的。一段里有一个落单的 `"`（英寸符号 `13"`，或者漏打了后引号），它会和后面的下一个 `"` 配成一对，中间整段都被当成引语而不标。只在同一行内配对已经限制了范围，但值得加一个单元测试（I8-15）。

约 25 个绑定，三种场合，⏎ 有四个意思（卡片：采用一条；面板：替换；面板降级时：复制；没有卡片时：App 自己的）。

### 一个新用户第一天需要记住什么

| 我想做的事 | 用鼠标 | 用键盘 | 第一天要记吗 |
|---|---|---|---|
| 改一个标出来的词 | 点下划线 → 点「采用」 | – | 不用记，看得见 |
| 把标出来的从头过一遍 | – | **⌃⌘J**，然后 **⏎ = 是**，**Esc = 停** | 记 ⌃⌘J。⏎ 和 Esc 不用记，是通用的 |
| 改 / 润色 / 翻译一段 | 选中 → 点旁边的按钮 | 选中 → **⌃⌘G** | 记 ⌃⌘G（鼠标用户连这个也不用记） |
| 把结果放回去 | 点底部的动作 | **⏎** | 不用记 |
| 不要了 | 点 ✕ | **Esc** | 不用记 |

**第一天：两个全局键（⌃⌘G、⌃⌘J），加上「⏎ 是、Esc 否」。** 其余的都应该是「屏幕上写着、想用再用」，不该出现在引导里。

### 该砍的

| 键 | 理由 |
|---|---|
| 卡片的 **⌫**（作为键） | 它是打字用的键，而且是点进错词之后最可能按的键。「忽略」已经有按钮。如果一定要留，只在 ⌃⌘J 打开的评审里生效 |
| 面板的 **⌘R** | 只在出错和等待时出现，那时屏幕上有「retry」按钮。留着键可以，从提示和文档里拿掉 |
| 面板的 **⌘D** | 旁边就是一个两格的切换控件。同上 |
| ⇥ 模式下的 **→ 跳过** | 方向键是挪光标的。⇥ 模式的用户选它就是因为不想被抢键，那就让跳过只有按钮，或者用 ⇧⇥ |

### 该合并的

| 现在 | 合并成 | 理由 |
|---|---|---|
| 卡片的「跳过」（⇥，留着下划线）和「忽略」（⌫，去掉下划线）和「这句都忽略」（按钮） | 一个「否」：⇥ = 不要这条（下划线消失），按钮同名。想留着以后再看的，按 Esc 就行 | 三种「不」，区别要试过才知道。第一天只需要「是 / 否 / 停」 |
| ⌃⌘J 和 ⌃⌘G | 值得试：⌃⌘G 在**没有选区、但光标所在的文本框里有标记**时 = 下一条建议；有选区时 = 面板 | 「叫它来」只需要一个键。风险是同一个键两种结果，所以要用原型试，不是直接改 |
| ⌃⌘T | 留着，但不教。⌃⌘G → ⌘3 能到同一个地方；选中按钮里也有 Translate | 它是给每天翻译的人的加速键，不是第一天的东西 |
| 面板的 ⏎（有时替换、有时复制）和 ⌘⏎ | ⏎ 的意思不要在我眼皮底下换。检查不过时保持「⏎ 替换」的标签，按下后在原位问一句「数字不一样：14 / 2:30，仍然替换？⏎ 确认」 | 现在的做法是安全的，但我两次法译英都被降级，原因都是误报（I8-04）。误报率这么高时，换键的含义比多问一句更伤人 |
| ⌘1–⌘4 | 留着，只放在悬停提示里（现在就是这样）。注意顺序是 改错 / 润色 / 翻译 / 语气，⌘3 是翻译不是语气 | 标签本身看得见、点得到 |

## 下一步最值得做的 3 件事（按对「用着顺」的贡献排序）

1. **点击打开的卡片不接管打字键（I8-01）。** 这是现在唯一还会「拿走我一个键」的路径，而且拿的是最常用的 ⌫ 和 ⏎。做法很小：`open()` 加一个参数，只有 ⌃⌘J 进来的才启用按键拦截。做完之后「⏎ 还是 ⇥」的争论基本就没有输家了。
2. **把「母语起草 → 地道的外语」做成一步到位的路径（I8-02、03、04 一起）。** 记住翻译方式；显示润色改了什么；时间写法不再把 ⏎ 降级。现在是 4 个动作 + 两次等待 + 最后只能复制；做完是 2 个动作（选中 → Translate → ⏎）。对非母语写作的人，这是这个产品比 Grammarly 多出来的那一块。
3. **把「否」收成一个，把键减到第一天两个（I7-07、I8-06、07、11）。** 卡片只留 是（⏎）/ 否（⇥）/ 停（Esc），按钮和键同名；计数写「还剩 N 条」；结束语说实话；在卡片上教一次 ⌃⌘J。这件事不加功能，只减东西，但它决定了第二天用户还记不记得怎么用。
