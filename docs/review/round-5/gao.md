# 高远（律师，中英文合同和客户信件）— 原型试用 Round 5

## 结论（评分 5/10；现在这样我不会每天用：去向标记和按 App 询问做得认真，但「只用本机」能被绕开，点一下 ⌘R 整个 App 会崩，润色会把中文条款整段改成英文）

我最在意两件事：文字去了哪里，合同里的数字和当事人有没有被改。
- 好的方面：面板右上角的去向标记每次都在，用 API 时是橙色。第一次在某个 App 里用 API 会先把要发出去的原文摊开再问。剪贴板方式的代价在引导和设置里都说了实话。历史记录确实只在内存里（我读了 `AppState.swift`）。保护检查拦下了模型擅自把「2月30日」改成「2月28日」。
- 不好的方面：Word 已经放进「这些 App 里只用本机的模型」，在面板右上角换成 API，再按一下 ⏎，文字就发出去了，而且以后在 Word 里都记住允许。没读到选区、在面板里手动输入（或者点「用剪贴板里的文字」）时，完全不看这个名单，也不问一声。对我来说这两条都是「会泄露」。另外 ⌘R 重试一次 App 就崩了（复现两次），润色把一条中文付款条款整段改写成了英文。

这几处修好以前，我只会在 Word 里用改错，而且只配本机模型、不配 API。真要用 API，我宁可另装一个不配本机模型的工具，免得两种混在一起出错。

## 我的任务和过程

机器说明：我的人物用 Mac Studio 64 GB，这次实测在 M5 Pro 24 GB 上，LM Studio 同时有其他 4 位评审在用。下面的速度按这台机器的实测写。

### 任务 1：第一次打开，引导里选本机模型

1. `--launch --fresh`，引导是英文（`01-start`）。`set:gb_ui_language=zh` 之后重新打开，变成中文（`02-onb1`）。默认的「母语」是英语，因为这台机器的系统语言是英语。我会改成中文，但测试接口不能点下拉框，所以没改。
2. 第 2 步「试一下翻译」（`03-onb2`）。选中示例，按 ⌃⌘T，前两次面板都说「没有读到选中的文字」。先执行 `focus` 再试就成功了（`06-onb2-tr3-1`）：系统翻译 · 在这台 Mac 上，译文正确。前两次失败我判断是测试接口的问题（窗口不是 key window），不算进问题清单。面板底栏写「不能确认这里可以编辑，所以默认是复制」，但这是 App 自己的示例框，这句话有点奇怪。
3. 第 3 步（`07-onb3`）显示已允许辅助功能，下面单独一段讲剪贴板：「选中的文字会短暂经过系统剪贴板（几百毫秒后恢复），剪贴板管理器可能记下它」。**这正是我想知道的，说得清楚。**
4. 第 4 步（`09-onb4-local`）有两张卡片。选「用这台 Mac 上的模型」后显示「LM Studio 已连上」，模型是「Qwen3 14B（已在内存里）（推荐）」。点「用这个模型」，直接跳到第 5 步。
5. 第 5 步改错示例（`11-onb5-fix-1`）。标记是「这台 Mac · LM Studio · qwen3-14b」，4 处改动都对。按 ⏎ 后示例框里真的被替换了，小条提示「已替换，⌘Z 可撤销」。
6. 从打开到第一次成功改错：5 步，约 8 次点击，没卡住。

### 任务 3：在 Word 里改合同条款（本机模型）

先用 `simulate` 的 JSON 造出 Word 里的选区，后来把 Word 加进了只用本机的名单。

1. 中文付款条款（`20`）：只改了「的的」，漏了「开据」。⏎ 是「写为修订」，qaLog 记的是 `word.trackedChange 1 changes`。金额、日期、甲乙方都没动。
2. 英文许可条款（`22`）：pays、untill、it's 三处都改对，5%、(30)、USD 250,000、9.2(b) 都没动。我敢直接写成修订。
3. 保密条款，三段，故意写了一个不存在的日期 2029年2月30日（`23b`）：
   - 模型**把 30 改成了 28**。保护检查把这一处标成「保护内容」（带锁），底部写「1 处保护内容被改动」，⏎ 退成复制。这是我最想要的那道保险，确实生效了。
   - 但这处改动默认是「已采用」。按 ⏎（复制）拿到的结果里就是 28 日。按 ⌘⏎ 会写进 Word。
   - 模型还在三处换行前加了两个空格（Markdown 的换行写法），diff 里显示成 3 处改动 `↵ → ␣␣↵`。这些会变成 3 条毫无意义的修订（G5-07）。
   - 我把 4 处全部撤回（`24`）：「1 处保护内容被改动」还挂在那里；diff 视图的段落换行不见了，行距也乱了；底部是「4 处 · 采用 0」，⏎ 却还是「写为修订」。
4. 名单生效以后，API 是当前引擎，在 Word 里改错（`41`）：标记是「这台 Mac · LM Studio」，没有询问，没走 API。**正常路径挡住了。** 只是面板上没有任何一句话告诉我「Word 设成了只用本机」，看起来和平时一模一样。这次删掉重复的「为止」是对的，却被检查报成「删掉了原文里的词：为止」，⏎ 退成复制（误报）。
5. 英文条款润色（`52`）：aggregate liability 改成 total liability，「the date falling eighteen (18) months after」改成「the date eighteen (18) months following」。这两个都是固定的合同用语，我不会接受。好在 Word 修订可以逐条拒绝。数字都没动。
6. **中文条款润色（`53`）：整段被改写成英文**，「Article 3.2 Party B shall pay to Party A … RMB ONE MILLION TWO HUNDRED THOUSAND YUAN」。面板只报「1 处保护内容被改动」，没报「结果换成了另一种语言」，⌘⏎ 写为修订仍然能用。diff 里的长改动块横向撑出了面板，文字被截掉（G5-04）。

### 任务 4：同时配本机和 API，在只用本机的 App 里试 API

1. 运行 `engine:api=…|local`，再运行 `engine:active=api`。
2. Word 已在名单里。打开面板，在结果出来之前执行 `panel:engine=api`（等于点右上角的标记换引擎）（`42`）：标记变成橙色「API · api.openai.com」，面板显示「模型没有输出任何内容 / 结果是空的」。这是被取消的本机请求结束时照样把结果写成「完成」，盖掉了本该出现的询问（G5-08）。
3. 按 ⌘R（`43`）：面板问「在 Microsoft Word 里选中的文字会发给 api.openai.com，允许吗？」，按钮有「不允许」「只这一次」「允许，在 Microsoft Word 里记住」。**Word 明明在只用本机的名单里，面板却提供发给 API，还提供「记住」。**
4. 按 ⏎（`44`）：直接按「允许并记住」处理，文字走了 API（测试环境里实际转给了本机），Word 从此进了「已允许」列表。
5. 读代码确认：`PanelModel.engine` 先看 `engineOverride`（面板里手动选的引擎），后看 `localOnlyApps`。标记菜单（`PanelView.swift` 91 行）不管在什么 App 里都列出全部引擎。
6. 手动输入（`45`）：`simulate:manual` 之后在面板里输入一句合同条款，按 ⏎，结果出来了，标记是 API，**中间没有任何询问**。代码上，`submitManual()` 生成的 `Capture` 不带 App，`run()` 里按 App 询问的条件是 `cap.app?.bundleID` 不为空，所以不问；`localOnlyHere` 也是 false。也就是说：在 Word 里没选中文字时会出现输入框，这时我把条款粘进去，或者点「用剪贴板里的文字」，文字就会直接发给 API，名单和询问都不起作用（G5-02）。真实的 Word 路径我用 simulate 造不出来（`manual` 预设不带 App），这一条是按代码推出来的，但推理链很短。

### 任务 5：第一次在某个 App 里用 API 的询问（邮件、Chrome 里的客户信）

1. Mail，客户信（英文）（`30`）：先把原文全部展开，再问「在 Mail 里选中的文字会发给 api.openai.com，允许吗？」，下面写着「上面『原文』就是要发出去的内容」。**这是我见过最诚实的询问框**，信息正好够用。
2. 点「不允许（改用本机模型）」：自动改用本机，标记变成「这台 Mac」，结果正确。再次打开时还会问，说明「不允许」不会被记成「永远不允许」，没问题。
3. 「只这一次」→ 下次还问，对。
4. 在询问框里按 ⏎ 等于「允许，在 Mail 里记住」，之后再也不问了。按钮上看不出哪个是默认（没有一个是蓝色或加粗的）。我写信时习惯按回车，一按就永久放行了（G5-05）。
5. Chrome 里的 Gmail，中文客户信，剪贴板方式（`50`、`51`）：原文默认展开，写着「处理期间请不要点别处，否则这次只能复制」；拒绝 API 后用本机，「做为」改成「作为」，对。结果视图里信件的空行不见了（原文有空行，diff 视图没有）。
6. 第一次配 `gpt-4.1-mini` 时，请求被转到 LM Studio，得到 `HTTP 400: Invalid model identifier …` 的英文原始报错（`33`）。这是测试环境的问题，后来把模型名改成 qwen/qwen3-14b 就好了。但这说明遇到服务端报错时，面板会把原始 HTTP 文本原样给用户看。

### 任务 6：崩溃

- 在面板有改动（diff 里有改动块）时，按 ⌘R 重试或在标记菜单里换引擎，**整个 GrammarBuddy 退出**。崩溃报告：`ChangeChip.body.getter PanelView.swift:454`，`Array index out of range`。我复现了两次（07:46、07:54）。同一时段其他几位评审的实例也有同样堆栈的崩溃报告（07:45、07:46、07:48）。崩了以后内存里的历史全丢，面板里的结果也没了（G5-03）。

## 优点

1. **询问框把要发出去的原文摊开再问**，按钮分成「不允许（改用本机模型）」「只这一次」「允许并记住」，拒绝后自动改用本机，不会让我卡住（`30`、`50`）。
2. **去向标记每次都在**，用 API 时是橙色，本机时写「这台 Mac · LM Studio · 模型名」，没有夸大成「不离开电脑」（`11`、`42`）。
3. **保护检查真的拦下了改日期**，⏎ 自动退成复制，并且在改动上加锁标（`23b`）。中文金额（大写和阿拉伯数字）、条款编号、甲乙方、公司名称在改错里一次都没被动过。
4. **剪贴板的代价在引导第 3 步和隐私页都说了实话**（「剪贴板管理器可能记下它」），代码和说法一致：读完马上恢复，带 Transient 标记。
5. 历史记录确实只在内存里（读代码确认）。API key 放在钥匙串里，不在 UserDefaults 里。
6. Word 里 ⏎ 默认是「写为修订」，正合律师的习惯：模型改错了，我在 Word 里拒绝那一条修订就行。
