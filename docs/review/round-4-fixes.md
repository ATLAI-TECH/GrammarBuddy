# Round 4 处理说明（多语言模型实测，设计稿 v4 → v5）

这一轮评的不是设计稿，是模型的真实输出。两个本地模型（gemma-4-e4b、gemma-4-12b）在六种语言的 41 条语料上各跑一遍，六位模拟的母语文字编辑逐条打分。第三个模型（qwen 27B）在 24 GB 的机器上跑不动，放弃。

报告：`round-4/zh.md`、`fr.md`、`de.md`、`es.md`、`ja.md`、`en.md`。数据和结论汇总在 [`../MODELS.md`](../MODELS.md)。

## 各语言的打分

每格是「可直接用 / 小问题 / 不能用」的条数。

| 语言 | 条数 | gemma-4-e4b | gemma-4-12b |
|---|---|---|---|
| 英语 | 14 | 7 / 7 / 0 | 10 / 2 / 2 |
| 中文 | 9 | 1 / 6 / 2 | 3 / 1 / 5 |
| 法语 | 6 | 2 / 4 / 0 | 3 / 1 / 2 |
| 德语 | 6 | 3 / 1 / 2 | 3 / 0 / 3 |
| 西班牙语 | 6 | 3 / 3 / 0 | 5 / 0 / 1 |
| 日语 | 5 | 2 / 3 / 0 | 3 / 0 / 2 |

12b 的「不能用」几乎全是空输出。

## 最重要的发现和处理

| 发现 | 谁提的 | 怎么处理（章节号指 v5） |
|---|---|---|
| **模型用删除代替改正，现有检查全部放行。** 中文把错别字「一至」整词删掉，德语把该挪到句末的 müssen 删掉 | ZH4-01、DE4-01（都是 P0） | §6.5 重写：改错做「词保留检查」，丢了实词就拦。差异视图把「挪了位置」和「删掉了」显示成两种样子。提示词加「不能用删除代替改正」 |
| **按改动比例判断跑偏，两头都不对。** 正确的德语改错会超过 40%；正常的润色改动 56%–80%，每次都会报警 | DE4-02、ZH4-02、FR4-07、EN4-05 | §6.5：去掉比例阈值。润色和语气不做这类检查，并直说它们的结果必须由人看过 |
| **翻译的数字比对查不出千分位和小数点互换**（西语 `1.400` 原样进了英语） | ES4-01（P0） | §6.4：按源语言和目标语言的地区规则把数字解析成数值再比 |
| **速度比目标慢一个数量级，思考关不掉** | EN4-01、DE4-03、JA4-01 | §6.6 改成目标和实测并列，写明 2 秒的目标在找到不思考的模型之前不成立。§12 第 11 项提到 M2a 开头，先于写功能 |
| **思考吃掉输出额度，12b 有 14 条空输出** | EN4-03、ZH4-04、ES4-08 | §7.2：默认不设 `max_tokens`，改用「正文超过原文 3 倍就中断」、超时和 Esc |
| **「只改了大小写就标出」在德语、法语、西语、英语里天天误报** | DE4-04、FR4-06、ES4-06、EN4-04 | §6.4：收窄到看起来像记号的词（全大写、词中有大写、含数字、在保护词表里） |
| **模型擅自加 Markdown 星号**（给学名和基因名） | EN4-02、ZH | §6.3 加一条清洗；§6.4 检查强调记号的数量；提示词加「不要新增格式」 |
| **英译法没有用不换行空格**（查了码位，全是普通空格） | FR4-02 | §2.5：不靠模型，清洗后用规则换 |
| **不换行空格的保护用告警是错的**，两种空格肉眼分不出 | FR4-01、FR4-03 | §6.3：程序按位置自动换回，不问用户 |
| **清洗会削掉正确的法语引号** | FR4-05 | §6.3 的规则改了；脚本里对应的错也修了 |
| **确认输入法候选词的回车，松开时会被当成提交** | ZH4-12、JA4-02 | §2.3：只认「按下也是面板收到的」那次松开。中文和日文输入法进 M0 清单 |
| **只差一个重音的改动在差异里看不出来**（`Cuando` → `Cuándo`） | ES4-03 | §6.5：词内再做字符级标记，朗读带「加了重音」 |
| **中文、日文按字做差异，会把一处改写碎成一串单字** | ZH4-03、JA | §4.2：用 NLTokenizer 分词。分词够不够用列为 §12 第 15b 项 |
| **日语的文体混用和假名 / 汉字写法没有交代** | JA4-04 | §6.1：文体按多数统一，看不出多数就不动；不改写法选择。后一点评审自己标了有争议 |

## 没有处理、留到 M2a 的

- 评审建议加进语料的约 90 句（各报告末节），M2a 并入 `corpus.json`。
- 语料的缺口：法语原文里没有不换行空格；日语只有 5 条；没有 100 词以上的条目；每条只跑了一次。
- 西班牙和拉美变体怎么让用户选（ES4-04、ES4-05）：设计稿 §2.5 已有地区变体，细节到做翻译时定。
- 另做一个不经过模型的「法语排版」操作（FR4-04）：记下，不在 0.1。
- 口语里可接受的用法（德语 `wegen dem`）改不改、英译德用 Sie 还是 du：到 0.2 的「正式 / 非正式」开关一起考虑。
- 各报告里其余的 P2。

## 要注意的一点

这批数字是用评审之前的提示词和脚本跑出来的。评审之后改了提示词、去掉了 `max_tokens`、修了脚本的两个错，都**没有重跑**。v5 里新写的词保留检查也还没有实现，它在六种语言上会不会误报是未验证的（§12 第 15b 项）。
