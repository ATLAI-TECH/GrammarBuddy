# 第 7、8 轮：用着顺不顺（实时标记、键盘采用、段落改写、翻译并润色），共用说明

第 5 轮试的是面板。之后产品变了很多：光标进了文本框就**自动在原位置标出错误**（紫色下划线），点一下或按快捷键打开小卡片，**回车采用并跳到下一条**；选中文字后旁边出现「改错 | 润色 | 翻译」按钮；翻译里多了「翻译并润色」。这两轮只评一件事：**一个真的在写东西的人，用起来顺不顺。**

第 7 轮：试用并报问题。第 8 轮：同一个人回来复查上一轮的问题有没有改好，再试一遍。

## 现在的交互（你要评的就是这个设计对不对）

1. **实时标记**：光标在文本框里时自动开始。一句一句查，离光标最近的先查。有问题的词下面出现紫色下划线。只用本机模型。
2. **打开一条建议**：点有下划线的词，或者按 **⌃⌘J**（跳到光标之后的第一条）。卡片出现在这个词的上方：`原词 → 新词`、第几条 / 共几条、「采用 / 忽略 / 这句都忽略」。
3. **卡片开着时的按键**：**⏎ 采用并跳到下一条**，**⇥ 跳过到下一条**，**Esc 关闭**。按任何别的键：卡片关闭，这个键照常进到 App 里。卡片没开时，⏎ 永远是 App 自己的换行。
4. **段落改写**：选中一段 → 旁边的按钮点「润色」（或 ⌃⌘G 打开面板后 ⌘2）→ 面板里看差异 → ⏎ 放回。
5. **翻译并润色**：选中 → 「翻译」→ 面板里出系统翻译 → 点「翻译并润色」→ AI 翻译并润色成像母语者写的。

## 怎么操作

每人一个测试实例和一个**专属的宿主 App**（不要碰别人的）：

```bash
cd <仓库目录>
Q=/tmp/gbqa/<代号>
qa/gbqa.sh $Q --launch --fresh --no-onboarding
# 所有人共用 LM Studio 里的同一份模型（必须这样配，否则每个实例各加载一份模型，内存不够）：
qa/gbqa.sh $Q 'engine:local=qwen/qwen3-14b; set:gb_live_use_configured=true'
```

把你自己写的测试文字（带真实的错误，像你的人物会写的东西）存成 `/tmp/gbtest/<代号>-1.txt`，然后放进宿主：

```bash
qa/host.sh textedit /tmp/gbtest/<代号>-1.txt     # 或 word / chrome / safari；只用分配给你的那一种
qa/gbqa.sh $Q 'live:app=<宿主的 bundle id>; live:on'      # com.apple.TextEdit / com.microsoft.Word / com.google.Chrome / com.apple.Safari
```

`qa/host.sh` 在后台打开宿主，不抢前台。**这台 Mac 的主人正在用电脑，不要把任何 App 切到前台**（不要用 `open` 不带 `-g`，不要 `osascript … activate`）。如果等了 40 秒一条标记都没有，在报告里记下来，再用 `open -g -b <bundle id>` 重试一次；还不行就换一段文字再试，然后如实报告。

之后用测试接口操作，每条命令后看 `cat $Q/state.json`：

| 命令 | 相当于用户做了什么 |
|---|---|
| `dump` | 写出 `state.json`：`liveMarks`（每条标记：原词 → 新词 @ 屏幕位置 宽×高）、`liveStatus`（还有几句在排队）、`liveCard`（开着的卡片）、`liveValue`（宿主里现在的文字） |
| `live:next` | 按 ⌃⌘J |
| `live:open=<i>` | 点第 i 条标记（从 0 数） |
| `live:key=return` / `tab` / `escape` / `a` | 卡片开着时按这个键（`a` 代表「继续打字」）。返回 `used=true` 表示这个键被卡片用掉了，`false` 表示照常进到 App |
| `live:accept=<i>` | 点第 i 条的「采用」 |
| `live:z` | 窗口从前到后的顺序（看下划线层是不是紧贴在宿主窗口上面） |
| `shot:<名字>@all` | 截 GrammarBuddy 自己的窗口（卡片、面板）。**宿主 App 的画面截不到**（没有屏幕录制权限），宿主里的文字看 `liveValue`，标记的位置看 `liveMarks` 的坐标 |
| `simulate:{…}` + `panel:` 命令 | 面板里的流程（润色、翻译），和第 5 轮一样，见 `docs/review/brief-app.md`。新增 `panel:polishTranslate` = 点「翻译并润色」 |
| `wait:<秒>`、`quit` | |

测时间：发 `live:on` 之后每隔一两秒 `dump` 一次，记下第一条标记出现用了几秒、全部查完用了几秒。

## 你要回答的问题

1. **等多久**：从光标进去到第一条下划线、到全部标完，各几秒？你会觉得慢吗？
2. **标得对不对**：该标的标了吗？有没有标错、把对的改成错的？有没有不该碰的东西被建议修改（专有名词、术语、引用、代码）？
3. **键盘流程顺不顺**：⌃⌘J → ⏎ ⏎ ⏎ 过一遍，中间有没有卡住、跳错、漏掉？⇥ 和 Esc 符合直觉吗？卡片开着时继续打字（`live:key=a`）会怎样？**⏎ 这个设计你同意吗**（会不会误采用、会不会抢走换行）？你更想要什么键？
4. **采用之后**：文字真的改了吗（看 `liveValue`）？其余标记还在不在、位置对不对？有没有越改越多？
5. **段落改写**：润色一段你自己写的话，改得好不好，差异看得懂吗，敢不敢按 ⏎？
6. **翻译并润色**：译文准不准、自然不自然？数字、术语、引用有没有丢？和只用系统翻译比呢？
7. **整体**：像不像「坐在旁边帮你看一眼的朋友」？哪一步会让你关掉它？和你现在用的工具比。

## 第 8 轮的补充（先读这一节）

第 7 轮发现：有些事只有宿主 App 在**前台**时才行（Word 给新文档建出文字内容、Safari 报告焦点所在的输入框、Chrome 和 Safari 里采用建议）。真实用户写东西时宿主本来就在前台，所以这一轮允许**轮流、短时间**用前台，用这个脚本（它会排队，一次只让一个评审用前台，做完自动切回原来的 App）：

```bash
qa/front.sh $Q <宿主 bundle id> '<测试接口命令，用 ; 分隔>'
# 例：让 Word 把新文档建出来，并等标记出现
qa/front.sh $Q com.microsoft.Word 'live:app=com.microsoft.Word; live:on; wait:12; dump'
# 例：在 Chrome 里连按三次回车采用
qa/front.sh $Q com.google.Chrome 'live:next; live:key=return; wait:2; live:key=return; wait:2; live:key=return; wait:2; dump'
```

- **每次占用前台不要超过 30 秒**，一个评审总共不要超过 8 次。这台 Mac 的主人在用电脑，每次都会打断他。能在后台做的（TextEdit 的全部；Word 里文档已经建出来之后的读和采用；Chrome 里的读和标记；面板的 `simulate:`）就在后台做。
- 除了 `qa/front.sh`，仍然不要用任何别的办法把 App 切到前台。

这一轮新增或变了的交互，请重点试：

| 变化 | 怎么试 |
|---|---|
| 「评审中」状态：从打开卡片到关闭，采用键 / 跳过键 / Esc 都被接住，包括写回的那一瞬间 | `live:next; live:key=return; live:key=return`（两次之间不等）：第二次应该 `used=true`，并且只采用了一条 |
| 最后一条之后 0.8 秒内多按的采用键被吃掉 | 把所有建议按 ⏎ 过完，紧接着再发一次 `live:key=return` |
| ⇥ 跳过的不再绕回来；走到末尾就结束 | 连续 `live:key=tab` |
| ⌫ = 忽略这一条（下划线消失） | `live:key=delete` |
| 只差大小写或带数字的记号（`FLC → flc`、`Col-0`）按键不采用 | 造一句会触发这种建议的话 |
| 插入 / 删除的卡片显示前后的词 | `shot:<名字>@all` 看卡片 |
| 引语（`«»` `“”` `"…"` `「」`、对话破折号开头的行）里的内容不标；面板里引语内的改动默认不采用 | 文字里放一句带错的引语 |
| 相邻的两处改动合并成一条（`por que → porque`） | |
| 翻译的语言栏右边固定有「系统 / AI / AI + 润色」 | `simulate:` 一段翻译后 `shot:` 看；`panel:polishTranslate` 仍然可用 |
| 设置里可以把采用键换成 ⇥ | `set:gb_live_accept_key=tab` 后，`live:key=tab` 采用、`live:key=right` 跳过、`live:key=return` 应该 `used=false` |
| 检查进行中菜单栏图标变成省略号气泡 | 截不到菜单栏，读代码确认即可 |

`live:key=` 现在认这些名字：`return` `tab` `escape` `delete` `right` `a` `space`。

报告里「上一轮问题的复查」一节：对照 `docs/review/round-7-fixes.md`，把你第 7 轮的每一条写明「改好了 / 没改好 / 没法验证」，标 ✅ 的要实际试过才算。
