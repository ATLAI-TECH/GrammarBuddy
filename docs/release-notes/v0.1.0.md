First public build of GrammarBuddy: a menu-bar writing helper for macOS that fixes, polishes and translates text in the app you are already writing in. It runs a model on your Mac, so nothing you write leaves the computer unless you choose an online service.

**Download `GrammarBuddy-0.1.0.dmg` below**, open it and drag GrammarBuddy to Applications. The app is signed and notarized. Requires macOS 15 or later on Apple silicon.

## What it does

- **Live check**: mistakes are underlined where you type, one sentence at a time, starting where your cursor is. Click an underlined word, then Accept (or press Return); Esc closes the card.
- **Select, then click**: after selecting text a small bar offers Polish and Translate. The result opens in a panel that shows every change; one click puts it back.
- **Translate** between your languages. The direction is chosen from the text; a swap button reverses it. System translation, AI, or AI + polish.
- **Models**: a built-in model (Qwen3 4B or 14B, downloaded once from inside the app), or LM Studio / Ollama, or an API key (OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, SiliconFlow, any OpenAI-compatible server), or Apple Intelligence. Live check only ever uses a local model.
- **Word**: suggestions are written straight into the document, with fields (Zotero / EndNote citations), footnotes, tables, comments and tracked changes left intact.
- **Per-app switch**: turn GrammarBuddy off in any app from the menu-bar menu; turn it back on there or in Settings.

## Tested

Accepting a suggestion was checked character by character against the expected text in TextEdit, Word (plain and with fields, footnotes, tables), a Safari rich-text editor and a Chrome text area: every accepted change landed exactly where intended.

## Known limits

- First start asks for the Accessibility permission (to read and replace text) and, for Word, Automation.
- The built-in model is downloaded from Hugging Face; there is no mirror setting yet.
- In Word, text inside tables, footnotes, headers and text boxes is not checked. Only the English interface of Word 16 was tested.
- Outlook, Slack, Notes, Mail and Pages use the same mechanisms but were not each verified.
- The setup guide still mentions the global shortcuts, which are now off by default (Settings → General).
- No automatic updates yet: new versions appear on this page.

GrammarBuddy 的第一个公开版本：macOS 菜单栏里的写作助手，在你正在写东西的 App 里直接改错、润色、翻译。模型在本机运行，除非你自己选择在线服务，否则文字不会离开这台电脑。

**下载下面的 `GrammarBuddy-0.1.0.dmg`**，打开后把 GrammarBuddy 拖进「应用程序」。App 已签名并通过 Apple 公证。需要 macOS 15 或更新版本、Apple 芯片。

## 功能

- **实时标记**：在你打字的地方直接给错误画下划线，一句一句查，从光标所在处开始。点有下划线的词，再点「采用」（或按回车）；Esc 关闭。
- **选中再点**：选中文字后旁边出现「润色 | 翻译」。结果在面板里逐处显示改动，点一下放回原处。
- **翻译**：在你的语言之间互译，方向根据文字自动判断，⇄ 按钮可以反过来。可选系统翻译、AI、AI + 润色。
- **模型**：内置模型（Qwen3 4B 或 14B，在 App 里下载一次），或 LM Studio / Ollama，或 API key（OpenAI、Anthropic、Gemini、OpenRouter、DeepSeek、硅基流动、任何兼容 OpenAI 的服务），或 Apple Intelligence。实时标记只使用本机模型。
- **Word**：建议直接写进文档，域（Zotero / EndNote 引用）、脚注、表格、批注和修订保持不动。
- **按 App 停用**：在菜单栏菜单里可以对任意 App 停用，之后在同一处或设置里重新启用。

## 已测试

在 TextEdit、Word（纯文字以及带域、脚注、表格的文档）、Safari 富文本编辑器和 Chrome 文本框里，逐字核对了「采用一条建议后的全文」：每一处修改都准确落在该改的位置。

## 已知限制

- 第一次启动需要授予「辅助功能」权限（用来读取和替换文字），用 Word 时还需要「自动化」权限。
- 内置模型从 Hugging Face 下载，暂时没有镜像设置。
- Word 里表格、脚注、页眉页脚、文本框中的文字不检查；只测试过英文界面的 Word 16。
- Outlook、Slack、备忘录、邮件、Pages 使用同样的机制，但没有逐个验证。
- 引导流程里仍然提到全局快捷键，而它们现在默认关闭（设置 → 通用）。
- 暂时没有自动更新，新版本会发布在这个页面。
