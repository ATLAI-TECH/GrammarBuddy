**Automatic updates.** From this version on GrammarBuddy keeps itself up to date.

**Download `GrammarBuddy-0.1.2.dmg` below** and drag it over the old copy in Applications. This is the last update you install by hand: 0.1.0 and 0.1.1 cannot update themselves. Signed and notarized; macOS 15 or later, Apple silicon.

## New

- **Automatic updates.** Once a day the app looks for a new version and offers it; you can also choose "Check for updates…" in the menu-bar menu. In Settings → General you can switch the daily check off, or let new versions download by themselves and install when the app quits.
- Checking only downloads a version list from GitHub. Nothing about you or your text is sent. A new version is verified with a key built into the app before it is installed.

## 新增

- **自动更新。** App 每天检查一次有没有新版本，有的话会提示；也可以在菜单栏菜单里点「检查更新…」。在设置 → 通用里可以关掉每天的检查，或者让新版本自动下载、在退出 App 时安装。
- 检查更新只是从 GitHub 下载一个版本清单，不发送任何关于你或你的文字的信息。新版本在安装前会用 App 内置的密钥验证。
