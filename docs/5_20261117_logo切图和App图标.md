# 5 · 2026-11-17 · logo 切图和 App 图标

## 目的

用户给了两张图：一张品牌板（彩色主标、字标、App 图标示意、三个黑色图形），一张菜单栏状态图（三种状态的菜单栏图标）。要识别出每个元素、切出来，做成 App 图标和菜单栏图标，并建一个 `logo/` 文件夹放这些东西。

## 方法

1. 两张原图都是 1536×1024 的位图（没有矢量源）。先看图识别内容，再用程序找边界：把和背景色差超过阈值的像素按列投影，得到每个元素的包围盒。
2. 建 `logo/`：
   - `logo/source/`：两张原图（`branding-board.png`、`menu-bar-states.png`）。仓库根目录原来的 `GrammarBuddy logo.png` 和品牌板是同一个文件（逐字节相同），已移走，不再重复存。
   - `logo/make_icons.py`：一个脚本做完全部切图和导出，可以重复运行。
   - `logo/cut/`：切出来的每一块。
3. 各元素的做法：
   - **彩色主标**：从品牌板左上切出；字标的第一个字母伸进了包围盒，先涂掉；背景只去掉「和边缘连通」的部分，边缘像素按离背景色的距离给半透明。
   - **字标**：同样的方法切成透明底。
   - **App 图标**：品牌板上的示意图只有约 330 像素，太小。改为按 macOS 图标规范重新合成：1024 画布、824 的圆角方块、淡淡的自上而下渐变、底部软阴影，把主标放大到最长边 600 像素放在中间。导出 16 到 512 各 1x / 2x 共 10 个尺寸。
   - **菜单栏图标**：用菜单栏状态图里的三个（为小尺寸简化过的），不用品牌板上细节多的那三个。按亮度转成「黑色 + 透明度」的模板图，系统会自动适配深色和浅色菜单栏。三个状态用同一个画布、同一个比例、同一个左下角对齐，切换状态时「G」不会跳动。导出 20×18 点的 1x / 2x / 3x。
4. 接进 App：
   - 新建 `GrammarBuddy/Resources/Assets.xcassets`（`AppIcon` + `MenuBarNormal` / `MenuBarPaused` / `MenuBarDot`）。
   - `project.yml` 加 `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon`，重新生成工程。
   - `AppDelegate.updateIcon()`：平时用 Normal，暂停时用 Paused（划线），正在检查时用 Dot（带圆点）；快捷键被占用时仍用系统的感叹号气泡。
5. 脚本会生成一张检查图 `logo/cut/_check.png`：各尺寸的 App 图标、深浅两种菜单栏上的三种状态、深色底上的主标。

## 结果

- `logo/cut/`：`mark.png`（透明底主标）、`wordmark.png`、`app-icon-1024.png`、`menubar-{normal,paused,dot}.png`、`glyph-detailed-{normal,paused,dot}.png`（品牌板上细节多的版本，备用）。
- 构建成功，App 包里有 `AppIcon.icns` 和 `Assets.car`，Info.plist 的图标名是 `AppIcon`。App 已用新图标重新启动。
- 检查图看过：App 图标在 16 像素下仍能认出蓝紫色的 G；三种菜单栏状态在深浅两种底色上都清楚。

## 踩坑

- 品牌板上的 App 图标示意不能直接用：太小，而且带着自己的阴影和背景，放大会糊。
- 主标的包围盒里混进了字标「G」的左边缘（两者在水平方向上有重叠），要先涂掉再去背景。
- 去背景如果按「接近白色就透明」来做，水豚的浅色部分会变成半透明；只去掉和边缘连通的背景才对。
- 用 `grep error` 过滤构建输出，会匹配到编译参数里的 `-Werror`，刷出一大屏无关内容。应该匹配 `: error:`。

## 经验

- 图标一律由脚本从原图生成，不手工导出；换了设计只要替换 `logo/source/` 里的图、改几个坐标再跑一遍。
- 菜单栏图标用模板图，不要自己做深色版。
- 多个状态的图标共用画布和对齐点。

## 还没做、已知的限制

- 没有矢量源：App 图标里的主标是从约 400 像素放大到 600 像素的，1024 尺寸下边缘略软。有 SVG 或更大的原图时应替换后重新生成。
- 菜单栏里的实际效果我截不到图（没有屏幕录制权限），需要用户自己看一眼大小和粗细是否合适。
- 「带圆点」的状态现在表示「正在检查」，这是我的选择；设计者的本意也可能是「有新建议」。
- README 还没有放 logo。
- 这些改动还没有提交。
